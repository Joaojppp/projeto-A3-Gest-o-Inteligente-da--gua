## Requisitos Funcionais (RF)
- **RF01:** Ingestão e tratamento contínuo de dados de vazão e pressão vindos de hidrômetros/sensores IoT[cite: 7, 10].
- **RF02:** Módulo de IA preditiva para detecção automática de anomalias e vazamentos com base na linha de base[cite: 4, 7, 10].
- **RF03:** Emissão automatizada de alertas de severidade (média, alta e perigo) e notificações push/e-mail para os gestores e clientes[cite: 4, 7, 10].
- **RF04:** Gestão de ordens de serviço e ações de mitigação (como fechar registro remoto).

## Requisitos Não Funcionais (RNF)
- **RNF01:** Interface web responsiva (HTML, CSS e JavaScript) contendo o painel operacional e o aplicativo simulado do cliente.
- **RNF02:** Segurança, conformidade e anonimização de dados residenciais de acordo com a LGPD[cite: 10].
